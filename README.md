# Wandering Trader Alert

Fabric mod for Minecraft 26.2 (Fabric Loader 0.19.5+, Fabric API, Java 25).
Warns all players with a chat message, action bar text and a bell sound
when a wandering trader spawns or is summoned.

Download the jar from the Releases page (or the latest Actions run), put it
in your `mods` folder together with Fabric API.
